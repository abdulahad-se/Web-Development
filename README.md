# Web-Development

A personal web-development learning notes and practice collection covering HTML, CSS, JavaScript, layouts, responsive design, and practical exercises.

## Repository Contents

- `Html` — HTML5 lessons, exercises, forms, links, images, tables, semantic elements, media, SEO, and Core Web Vitals
- `CSS` — CSS3 exercises covering styling, the box model, Flexbox, Grid, positioning, colors, and responsive layouts
- `Javascript` — JavaScript fundamentals, variables, data types, arrays, objects, functions, scopes, control flow, loops, and browser scripting

Each folder contains its own README with more detailed information about that section.

## Purpose

This repository documents my web-development learning journey through structured lessons, notes, examples, and practical exercises in HTML, CSS, and JavaScript.

It is intended for:

- Personal learning
- Portfolio presentation
- Reviewing web-development concepts
- Practicing HTML, CSS, and JavaScript
- Helping beginners understand web-development fundamentals

## How to Run the Files

Open any HTML file in a web browser.

For a better development experience, open the repository in Visual Studio Code and use the Live Server extension.
