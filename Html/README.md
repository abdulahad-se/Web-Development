# 🌐 HTML5 Learning & Practice

This folder contains a structured set of HTML5 exercises, practice modules, and lesson files covering core web development concepts.

---

## 📁 Directory Structure & Topics Covered

### 1. Fundamental HTML Lessons
- **`index1.html` - `index3.html`**: Basic HTML page structure, document metadata, heading hierarchy, and text formatting tags.
- **`index4.html` - `index6.html`**: Anchor tags, absolute/relative hyperlinking, images, lists (`<ul>`, `<ol>`), and tables.
- **`index7.html` - `index10.html`**: Forms, input types, semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`), and layout structure.

### 2. Media & Resources
- 🎵 **`audios/`**: Embedding audio controls and supporting multiple sound formats.
- 🖼️ **`images/`**: Image asset management, alt tags, and responsive image syntax.
- 🎬 **`videos/`**: Video player implementation, source tags, and media attributes.

### 3. Deep Dives & Best Practices
- **`A_Html.txt`**: Core theoretical notes and syntax reference.
- **`SEOAndCoreWebVitals.txt`**: Meta tags, SEO optimization principles, performance, and Core Web Vitals considerations.
- **`practice/`**: Custom practice pages, template experiments, and mini-exercises.

---

## 🛠️ How to Run
1. Open any `.html` file in **Visual Studio Code**.
2. Right-click the file and select **Open with Live Server** (or open the file directly in any browser).
