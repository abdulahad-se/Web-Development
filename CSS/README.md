# 🎨 CSS3 Learning & Practice

This folder contains a structured set of CSS3 exercises, practice modules, and stylesheet files covering core web styling and design concepts.

---

## 📁 Directory Structure & Topics Covered

### 1. Fundamental CSS Lessons & Exercises
- **`index3.html` – `index8.html`**: CSS syntax, inline/internal/external styling, color properties, background images, and typography.
- **`index9.html` – `index15.html`**: Box model mechanics (margins, padding, borders), display properties, pseudo-classes, and pseudo-elements.
- **`index16.html` – `index23.html`**: Advanced layouts using Flexbox, CSS Grid, positioning (`relative`, `absolute`, `fixed`, `sticky`), and responsive components (navbars, card layouts).
- **`index18part2.html`**: Specialized layout exercise and component building.

### 2. Stylesheets & Assets
- 🎨 **`style1.css` & `style2.css`**: Core external stylesheets containing modular styling rules and responsive layout rules.
- 🖼️ **`myimage.png` & Assets**: Media assets used for practicing background placement, image styling, and container bounds.

### 3. Topic Guides & References
- **`A_CssTopics.txt`**: Curated CSS topic index, key syntax reference, and learning resources.
- **`icolors.html`**: Dedicated practice file for experimenting with color models (HEX, RGB, HSL) and color management.

---

## 🛠️ How to Run
1. Open any `.html` file in **Visual Studio Code**.
2. Right-click the file and select **Open with Live Server** (or open the file directly in any browser).
